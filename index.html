ParkViewRT — vision-based parking occupancy

Social media computing · NLP

What 20,050 Steam reviews say about FIFA 23

A full opinion-mining pipeline: cleaning, four hypothesis tests, six models on identical splits, and dictionary-based aspect sentiment across six facets of the game. The headline finding is a warning about defaults — TF-IDF with logistic regression beat a pretrained transformer by 15 F1 points.

Result
Logistic regression F1 0.8468 vs DistilBERT SST-2 0.6999; BiLSTM trained from scratch 0.8231
Insight
Across six aspects, price/monetisation was both the loudest (4,207 mentions) and the angriest (84.22% negative); graphics was the happiest and the quietest

Data mining · imbalanced classification

Insurance fraud: a prediction you can explain

Fraud is 5.98% of the claims in this dataset, which makes accuracy a liar. So the model is tuned on fraud-class F1 with an explicit decision threshold, and every prediction is paired with human-readable association rules mined from the same data — 285,919 candidates filtered down to 130 that hold up.

Result
Gradient boosting, threshold 0.150: ROC-AUC 0.891, PR-AUC 0.354, fraud recall 0.486 at precision 0.296
Negative result
SMOTE raised recall but cut PR-AUC from 0.354 to 0.195 — so it was dropped, and that is documented
Stack
Python · scikit-learn · imbalanced-learn · mlxtend (FP-Growth) · Streamlit · Plotly
Scale
15,420 claims · 33 attributes · 4 notebooks · 1,096-line Streamlit app

Visual information processing · ablation study

Does preprocessing help facial expression recognition?

A controlled study rather than a leaderboard chase: four data conditions crossed against six model families on FER-2013, holding the test set fixed at 7,178 images. The answer was no — the classical preprocessing pipeline that textbooks recommend made accuracy worse.

Result
YOLOv11n-cls baseline 65.42%; adding median + Gaussian + CLAHE preprocessing dropped it to 58.69%
Better lever
Class-balanced augmentation left accuracy flat but lifted disgust recall from 0.3063 to 0.7207 and macro-F1 to 0.6223
Stack
Python · Ultralytics YOLO11 · TensorFlow/Keras (VGG19, ResNet50) · scikit-learn (SVM, LR, RF on HOG + SIFT) · OpenCV
Scale
35,887 images · 4 conditions × 6 model families · 2,356 lines across 7 notebooks
